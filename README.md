# LynxOffice Command Line for Mac

LynxOffice offers a command-line tool that reads, edits and reviews Word, Excel, PowerPoint and PDF files from the Mac terminal.

## Install

```bash
brew install lynxoffice/tap/lynxoffice
lynxoffice help
```

The command is `lynxoffice`. Requires macOS 14 or later, on Apple silicon or Intel. Each build under [Releases](https://github.com/LynxOffice/lynxoffice-cli-mac/releases) is signed with KDAN's Developer ID and notarized by Apple.
