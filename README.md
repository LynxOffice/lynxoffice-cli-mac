# LynxOffice Command Line for Mac

LynxOffice offers a command-line tool that reads, edits, converts and renders Word, Excel, PowerPoint and PDF files from the Mac terminal.

> **Status:** not released yet. Signed and notarized builds will be published under [Releases](https://github.com/LynxOffice/lynxoffice-cli-mac/releases) with the first release.

## Install (from the first release)

```bash
brew install lynxoffice/tap/lynxoffice
```

The command is `lynxoffice`. Requires macOS 14 or later.
